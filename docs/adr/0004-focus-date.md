# フォーカス日はサーバー刻印のスタンプとして持つ

今日の予定は `期限(dueDate)` とは別の第三の概念 `フォーカス日(focusDate: YYYY-MM-DD|null)` として持つ。未来の計画ではなく「その日に集中するために今日の予定に入れた日」で、入力は日付ではなく `focusToday` フラグのみ受け、サーバーがJST今日を刻印する。翌日は一致しなくなり今日の予定から外れる。履歴表示は作らない。

## Considered Options

- クライアントが日付直指定: 未来の計画日と入り混じり、誤って未来日が入るため不採用。
- 履歴フィルタ (`focusDate` exact): 翌日空にしたい運用に不要なため不採用。`todayOnly` のみに絞る。

## Consequences

未来日のガードはMCP入力層に置き、storeはdumbに保つ (`期限` と同じ設計)。storeの `focusDate` 直指定は過去データ再現の裏口として残し、通常経路では使わない。
